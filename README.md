# AgileX Limo Docs (Obsidian Vault)

This repository is designed to be opened directly in **Obsidian** as a vault so you can browse the robot documentation with internal links, images, and notes.

## What this repo contains

- `AgileX Limo/Start.md` — recommended entry point.
- `AgileX Limo/Docs/` — longer-form documentation and TODO notes.
- `AgileX Limo/*.md` — app guides and command references.
- `AgileX Limo/*.png` — images used by the markdown files.

## Quick start (recommended)

1. **Download this repository**
   - Option A: `Code` → `Download ZIP` from GitHub.
   - Option B: clone it with Git:
     ```bash
     git clone <repo-url>
     ```

2. **Extract/open the folder locally**
   - If you downloaded a ZIP, extract it first.
   - Keep the folder structure unchanged so image links continue to work.

3. **Open Obsidian**
   - If you do not have it yet, install from: <https://obsidian.md/>

4. **Open the project as a vault**
   - In Obsidian, click **Manage vaults** (vault icon in the lower-left).
   - Click **Open folder as vault**.
   - Choose the repository root folder (the one containing `README.md` and `AgileX Limo/`).

5. **Start reading**
   - Open `AgileX Limo/Start.md` first.

## Tips for best results in Obsidian

- Use the **File explorer** pane to navigate notes by folder.
- Turn on **Settings → Files & Links → Detect all file extensions** if needed.
- Use `Ctrl/Cmd + O` to quickly search notes.
- Open the **Graph view** to visualize note connections.

## Troubleshooting

- **Images do not appear**
  - Ensure you opened the repository root as the vault (not a parent/child folder).
  - Confirm the `AgileX Limo/` folder and `.png` files are still present.

- **Internal links seem broken**
  - Keep original file names and folder structure.
  - Avoid renaming folders/files unless you also update linked notes.

- **Vault opens but looks empty**
  - Verify you selected the correct folder when opening as vault.
  - Re-open via **Manage vaults → Open folder as vault**.
